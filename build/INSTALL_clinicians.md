# Installer NeuroCogProfile / Installing NeuroCogProfile

Application 100% locale et hors ligne. Aucune donnee patient ne quitte
votre ordinateur. / Fully local, offline application. No patient data
ever leaves your computer.

---

## Francais

### Windows
1. Telechargez le fichier `NeuroCogProfile-windows-setup.exe`.
2. Double-cliquez dessus. Si Windows affiche un avertissement bleu
   (SmartScreen), cliquez sur **Informations complementaires** puis
   **Executer quand meme**. C'est normal pour une application non signee
   et cela n'arrive qu'une fois.
3. Suivez l'assistant (installation pour votre compte, sans droits
   administrateur). Lancez l'app depuis le menu Demarrer.
4. Windows 10 ou 11 requis (le composant Edge WebView2 y est deja
   present).

### macOS
1. Telechargez le fichier `NeuroCogProfile-macos.dmg` et ouvrez-le.
2. Glissez l'icone **NeuroCogProfile** sur le dossier **Applications**.
3. Au tout premier lancement, faites un **clic droit** (ou Ctrl-clic) sur
   l'app dans Applications, choisissez **Ouvrir**, puis **Ouvrir** dans
   la fenetre d'avertissement. C'est normal pour une application non
   signee et cela n'arrive qu'une fois; ensuite un double-clic suffit.
4. macOS 11 (Big Sur) ou plus recent requis.

## English

### Windows
1. Download `NeuroCogProfile-windows-setup.exe`.
2. Double-click it. If Windows shows a blue SmartScreen warning, click
   **More info** then **Run anyway**. This is expected for an unsigned
   app and only happens once.
3. Follow the wizard (per-user install, no administrator rights needed).
   Launch the app from the Start menu.
4. Requires Windows 10 or 11 (the Edge WebView2 component is already
   included there).

### macOS
1. Download `NeuroCogProfile-macos.dmg` and open it.
2. Drag the **NeuroCogProfile** icon onto the **Applications** folder.
3. On the very first launch, **right-click** (or Ctrl-click) the app in
   Applications, choose **Open**, then **Open** in the warning dialog.
   This is expected for an unsigned app and only happens once; afterward
   a double-click is enough.
4. Requires macOS 11 (Big Sur) or newer.

---

Pour supprimer l'app: Windows, via Parametres > Applications; macOS,
glissez l'app de Applications vers la Corbeille. / To remove it:
Windows, via Settings > Apps; macOS, drag the app from Applications to
the Trash.
